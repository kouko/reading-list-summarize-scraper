## 對你既有的資料做了什麼

驗收只新增暫存測試清單、設定與人工完成紀錄，沒有修改你的瀏覽器資料、筆記或正在執行的程式。此變更重新排列每次讀入的清單，不遷移或改寫既有資料；原有資料格式仍可讀取，無需備份轉換。

## 我代你決定的事

- **相同時間與無日期** — 保留同時間原順序，無日期放最後；日後改規則需調整排序與測試。
- **比較完整加入時間** — 同一天也按實際時間排序；改成只比較日期會改變同日順序。
- **沿用重複網址與完成跳過規則** — 保留首次遇到的資料，已完成項目不補入較舊替代；改動需另定選取規則。
- **共用既有排序入口** — 清單、批次與監看使用同一規則，不增加設定選項；若要不同排序方向需另加功能。
