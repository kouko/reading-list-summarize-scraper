# 網頁擷取失敗時自動重試

## Problem
kouko 從閱讀清單擷取網頁時，部分公開文章無法取得正文，需要手動改用顯示視窗的瀏覽器再試，造成處理中斷；也曾取得驗證頁而非正文，卻被當成成功並產生無用摘要。

## Proposed outcome
所有網站都能在一般擷取失敗後，自動獲得另一次取得正文的機會，減少逐篇手動重試，且不將登入頁或驗證頁誤當正文交付。

## Acceptance
1. 自動重試能力適用所有網站，不限特定網域。
2. 原先需要手動切換瀏覽器模式才能讀取的公開文章，可以由同一次執行完成擷取。
3. 重試後仍無法取得內容時，能明確得知擷取失敗。
4. 只取得登入頁或驗證頁而非正文時，不當成成功、不產生該頁的摘要。

## Constraints
- 先用 headless 嘗試抓取，失敗後改用 headed。
- 沿用目前專案與使用者指定的設定檔。
- 正確性優先；不可將錯誤頁面內容當成實際內文。
- 保留 headed_on_block 設定與原有反爬蟲驗證頁重試開關的效果。

## Value case
受益者為 kouko。已在公開貼文實測遇到必須手動改用顯示視窗才能取得正文的問題；目前替代方式是逐次手動重試。使用者已要求本次處理，並確認本次修改不會排擠其他工作。GO：已有實際擷取失敗與誤抓驗證頁的證據，值得本次處理。

## Out of scope
- 自動登入網站帳號。
